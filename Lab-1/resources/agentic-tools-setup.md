# Agentic tool setup · optional help

*Only if the Week 1 checklist install did not work. Pick one tool; you do not need all three.*

## Cursor
1. Download at cursor.com, sign in, open your repo folder.
2. Settings → Models: it works out of the box; you can add your OpenRouter key later.
3. Test: open chat, ask "summarize this repo."

## VS Code + Continue
1. Install the Continue extension from the marketplace.
2. In Continue settings, add OpenRouter as a provider with your key, model `google/gemini-3.8-flash`.
3. Test: highlight code, ask Continue to explain it.

## Claude Code (CLI)
1. `npm install -g @anthropic-ai/claude-code`
2. Run `claude` inside your repo folder and follow login.
3. Test: ask "what files are in this project?"

Stuck after 15 minutes? Post the exact error on Teams. Exact error, not "it doesn't work."
