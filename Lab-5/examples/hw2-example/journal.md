## Week 5 · Tool Contract

**Where I used it:** in Lab 5 our team's first tool was `rsvp`, and the agent's first diff put `student_id` in the arguments "so the model can say who is booking". The both-doors test passed and the RSVP worked, which is exactly why it was dangerous. **What I noticed:** a test that only checks the happy path cannot see an identity field. **Do differently:** write the "model cannot set identity" test before asking the agent for the tool.
